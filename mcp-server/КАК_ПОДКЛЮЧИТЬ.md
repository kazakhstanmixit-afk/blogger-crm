# Подключение CRM к Claude Desktop

## Что это
MCP-сервер позволяет Claude читать все данные CRM — блогеров, оплаты, бартеры, ТЗ, товары, расходы, статистику.

## Шаги

### 1. Скачать файл
Скачать файл `mcp-server/index.js` из репозитория (или попросить прислать).

Положить в любую папку, например: `C:\Users\ИМЯ\crm-mcp\index.js`

### 2. Убедиться что Node.js установлен
Открыть терминал (командная строка / PowerShell) и проверить:
```
node --version
```
Должно показать `v18.x.x` или выше. Если нет — скачать с https://nodejs.org

### 3. Открыть конфиг Claude Desktop
Найти файл конфига:
- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **Mac:** `~/Library/Application Support/Claude/claude_desktop_config.json`

Если файл не существует — создать его.

### 4. Добавить MCP сервер в конфиг
```json
{
  "mcpServers": {
    "blogger-crm": {
      "command": "node",
      "args": ["C:\\Users\\ИМЯ\\crm-mcp\\index.js"],
      "env": {
        "CRM_URL": "https://blogger-crm.onrender.com",
        "CRM_API_KEY": "mixit-crm-readonly-2026"
      }
    }
  }
}
```
> ⚠️ На Windows путь пишется с двойными обратными слешами `\\`
> На Mac: `"/Users/ИМЯ/crm-mcp/index.js"`

### 5. Перезапустить Claude Desktop
Полностью закрыть и открыть заново.

### 6. Проверить
В новом чате написать:
> "Покажи статистику по блогерам из CRM"

Claude должен использовать инструмент `get_stats` и вернуть данные.

---

## Доступные инструменты
| Инструмент | Что возвращает |
|---|---|
| `get_bloggers` | Все блогеры с ценами, охватами, статусом, менеджером |
| `get_payments` | Все оплаты — сумма, статус, кому, когда |
| `get_barters` | Бартерные запросы — адреса, товары, статус |
| `get_tz_requests` | Запросы ТЗ — ник, товар, формат, статус |
| `get_products` | Товары и их варианты ТЗ |
| `get_expenses` | Расходы |
| `get_stats` | Сводная статистика по всей CRM |

## Доступ только для чтения
Сервер не может изменять данные — только читать.

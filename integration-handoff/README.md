# Изменения Barter Box — готовый патч

Подключённый GitHub-аккаунт не смог отправить ветку в `sillangroup-png/barter-box-server` (403). Поэтому весь проверенный код передаётся здесь в `barter-box-pilot.patch`. Основная ветка Barter Box не менялась.

Исходная версия: `2c2513bd4c2c6e40e292b31c881ffb8144ba6933`.
Подготовленный локальный commit: `4ed658f` (в исходном репозитории на GitHub его нет).

Применять в отдельной ветке **копии Barter Box**, не в работающей директории сервера:

```sh
git switch -c review/mixit-flow-pilot 2c2513bd4c2c6e40e292b31c881ffb8144ba6933
git apply --check /path/to/barter-box-pilot.patch
git apply /path/to/barter-box-pilot.patch
node --test test/automation-flow.test.js
npm install
node test/http-flow.smoke.js
```

Если основной код уже изменился, сначала `git apply --check` и разбор конфликтов. Нельзя вслепую перезаписывать index.html или state.json.

Патч добавляет: компактный поиск товаров и точный подбор по ШК в существующей компьютерной форме; серверный расчёт себестоимости; независимую заявку на товар; очередь Саи и произвольных сборщиков двух городов; связь одной посылки с несколькими видео; подтверждение доставки через существующий маршрут; версионность видео в пилоте; сухую очередь передачи GATE тимлиду; нормализованный контракт ответов и утверждённых ТЗ. Подробности — `docs/automation-pilot.md` после применения.

Проверки: 20 unit-тестов Barter Box, отдельный сквозной HTTP-сценарий на реальном Express и временных синтетических данных. Вместе с CRM и контрактом Бриф-студии — 36 Node-тестов. Физический iPhone и браузерная проверка интерфейса ещё не выполнены.

Внешние отправки и включение флагов не выполнялись. Для исходящих WhatsApp нужны реальные подтверждённые контакты тимлидов и проверка payload Wazzup. Для ТЗ — подключение к действующему процессу утверждения. Для Instagram — проверенное подключение; приложение не управляет Instagram автоматически.

Реальных цен, каталогов, телефонов и банковских данных этот патч не содержит. Excel обрабатывается локальным `tools/prepare_catalog.py`, а результат импортируется в серверную базу, не в GitHub.

# Instagram pilot: marina / @marina_mixit_pr

Цель — робот Instagram для одного менеджера. Интерфейс на телефоне служит пультом; отправляет и читает браузер на Windows. Переписку в CRM повторно вводить не нужно после успешного распознавания сообщений.

## Подключение ноутбука

1. Установить Node.js LTS с nodejs.org, если ещё нет.
2. Скачать ZIP актуальной main репозитория и распаковать. Внутри `instagram-worker/windows` запустить `install-and-connect.cmd`.
3. В приложении `/discovery/` войти как `marina` и нажать «Подключить мой Instagram». Получить одноразовый код на 10 минут. Код создавать после установки зависимостей, если загрузка занимает долго.
4. В окне установщика оставить предложенный адрес CRM, ввести код. В открывшемся браузере вручную войти именно в `marina_mixit_pr`, пройти проверку Instagram. Пароль в CRM и чат не передаётся.
5. Вернуться в окно установщика и нажать Enter. Ключ робота запишется в приватный локальный `.env.local`, после чего робот запустится. Не закрывать рабочее окно, отключить сон ноутбука на время теста. Для повторного запуска — `windows/start.cmd`.

Привязка ограничена логином менеджера и ником аккаунта в настройках сервера. Код одноразовый; в базе хранится только хеш кода/ключа. «Отключить ноутбук» отзывает доступ. После ручного входа фиксируется числовой ID аккаунта из сессии; worker проверяет его перед каждым заданием. Подтвердить, что выбран правильный ник при входе, должен владелец аккаунта.

## Автоматизация

`INSTAGRAM_CONTACT_AUTOMATION_ENABLED=1`: распознанные текстовые ответы обрабатываются автоматически. Из явных сумм с валютой/«к», телефона и города создаются условия со ссылкой на исходное сообщение. Несколько разных цен требуют проверки, не становятся согласованной суммой. Подтверждённые вручную условия не перезаписываются. При полученном однозначном прайсе карточка автоматически передаётся тимлиду.

`INSTAGRAM_AUTO_DRAFT_ENABLED=1`: подготавливает стандартные обращения для кандидатов marina; `INSTAGRAM_PILOT_MAX_DRAFTS=5` ограничивает пилот пятью первичными черновиками. Это не автоматическая массовая отправка. Первый текст и адресат проверяются человеком.

Чтение пытается разобрать только ответы, которые естественно загружает сам интерфейс Instagram, с постоянными ID сообщений и подтверждённым единственным собеседником. Групповые/чужие диалоги исключаются. Если формат не распознан, система останавливает структурированное чтение, показывает скриншот и не выдумывает сообщения. Резервный DOM-адаптер требует проверенных селекторов. Реальная совместимость проверяется после входа, локальные тесты её не гарантируют.

Порядок реального теста: открытие чата → проверка адресата → одно согласованное сообщение → ответ → сверка текста/автора в CRM → проверка извлечённого прайса → уведомление тимлиду. До этого нельзя считать робот запущенным. Для просмотра ответа вначале нажать «Проверить чат»; фоновое чтение включать после успешной проверки.

## Сервер

```dotenv
BROWSER_PILOT_MANAGER_LOGIN=marina
BROWSER_PILOT_INSTAGRAM_HANDLE=marina_mixit_pr
INSTAGRAM_CONTACT_AUTOMATION_ENABLED=1
INSTAGRAM_AUTO_DRAFT_ENABLED=1
INSTAGRAM_PILOT_MAX_DRAFTS=5
```

Существующие функции CRM, оплаты и Apify Scout не меняются. Отдельные сервисы/платные ресурсы не создаются. До физического запуска установщика на Windows подключение ноутбука не выполнено.
